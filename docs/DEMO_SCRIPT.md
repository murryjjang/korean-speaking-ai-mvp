# 시연 발화 스크립트

회원님 시연 시 사용할 한국어 발화 시퀀스 모음. 시연 4 모드 (q1·q4·발표·생성형 대화) 라이브 흐름을 정리한다.

> NPC 응답은 LLM이 매번 다르게 생성한다. 아래는 예상 흐름이며 실제 시연에서 응답 문구가 달라질 수 있다. 폴백(mock 응답)이 발동해도 자연스럽게 진행할 수 있도록 멘트를 준비해 둔다.

---

## 1. q1 낭독 (제시문 따라 읽기)

회원님은 q1을 라이브 시연하지 않으나, 슬라이드에서 짧게 언급할 가능성이 있다.

- **제시문 (beginner-q1-reading 동등 수준)**
  "안녕하세요. 저는 오늘 오후에 병원에 갑니다. 병원에 가기 전에 약국에 들를 예정입니다. 진료가 끝난 후에는 집에서 쉬려고 합니다. 내일은 학교에서 한국어 수업이 있어서 일찍 자려고 합니다."
- **시연 멘트 예시**: "q1은 제시된 한국어 지문을 학습자가 자연스럽게 낭독하면 발음과 운율을 평가합니다. 평가 후 단어 단위로 첨삭이 표시되어 어떤 단어를 다시 연습해야 하는지 한눈에 보입니다."

---

## 2. q4 카페 미션 (대화)

목표: 결제 / 사이즈 / 매장-포장 / 음료 종류 등 미션 목표 달성.

| 단계 | 회원님 발화 | 예상 NPC 응답 | 폴백 (mock) |
| --- | --- | --- | --- |
| 1 | 안녕하세요. | 어서 오세요. 무엇을 도와드릴까요? | 동일 |
| 2 | 라떼 5잔 주세요. | 아이스로 드시겠어요, 따뜻한 걸로 드시겠어요? | 사이즈는 어떻게 해 드릴까요? |
| 3 | 아이스로 주세요. 여기서 먹을게요. | 네, 아이스 라떼 5잔 매장에서 드시는 걸로 준비해 드릴게요. 결제는 어떻게 도와드릴까요? | 결제는 카드/현금 중 어떤 것으로 하시겠어요? |
| 4 | 카드로 할게요. | 네, 카드 결제해드리겠습니다. 잠시만 기다려 주세요. | 동일 |

**미션 달성률**: 4/4 (인사 / 주문 / 매장 선택 / 결제) → 결과 페이지에 100% 표시

**시연 멘트 예시**: "카페 주문이라는 실제 상황을 NPC와 자연스럽게 대화하면서 풀어 갑니다. 미션 항목별로 달성 여부를 자동 판정하기 때문에, 학습자가 어떤 표현을 빠뜨렸는지 즉시 확인할 수 있습니다."

## 3. 발표 연습 ("한국의 겨울 날씨")

원고는 페이지 하단 "시연용 사전 작성 (겨울 날씨)" 버튼으로 한 번에 불러온다 (입력 시간 단축).

### 사전 작성 원고 (1분 분량)

> 안녕하세요. 저는 김학습자입니다.
> 오늘은 한국의 겨울 날씨에 대해 발표하겠습니다.
> 한국의 겨울은 매우 춥고 건조합니다.
> 보통 12월부터 2월까지 겨울이 이어집니다.
> 1월과 2월에는 기온이 영하로 떨어집니다.
> 특히 강원도 산간 지역은 눈이 많이 옵니다.
> 서울에서도 가끔 폭설이 내립니다.
> 이상 발표를 마치겠습니다. 감사합니다.

### 시연 흐름

1. "시연용 사전 작성 (겨울 날씨)" 버튼 클릭 → 원고 자동 채움
2. 교정 톤 선택 (기본: 격식체) → "AI 원고 교정하기"
3. 교정 결과 확인 후 "타이머 시작" → 위 원고를 그대로 낭독
4. 종료 버튼 → 카라오케 결과 / 발음 비교 결과 확인

**시연 멘트 예시**: "발표를 준비하는 학습자에게 가장 큰 부담은 원고 점검입니다. AI가 격식체·일반체·친근체 중 선택한 톤에 맞춰 자연스러운 한국어로 교정한 뒤, 타이머 발표 연습으로 이어집니다. 발표 도중 단어가 어떻게 인식되는지 카라오케처럼 따라 흐릅니다."

## 4. 생성형 대화 ("주말에 가볼 만한 명소 추천")

추천 주제 카드 첫 번째 (⭐ 시연 표시) 사용.

| 차례 | 회원님 발화 | 예상 NPC 응답 | 폴백 (mock) |
| --- | --- | --- | --- |
| 1 | 주말에 가볼 만한 곳을 추천해 주세요. | 어떤 종류의 장소를 좋아하세요? 자연이 좋은 곳, 도심 명소, 박물관 같은 문화 시설 중에서 어떤 게 끌리세요? | "주말에 가볼 만한 명소 추천"이라는 주제로 이야기해 볼까요? 어떻게 시작할까요? |
| 2 | 자연이 좋아요. | 그럼 북한산을 추천드리고 싶어요. 등산하기도 좋고 단풍이나 설경을 볼 수 있어 사계절 모두 좋답니다. | 자연을 좋아하시면 북한산 같은 산이나 한강공원도 좋아요. |
| 3 | 거기 어떻게 가요? | 지하철 4호선을 타시고 수유역에서 내리신 다음 마을버스로 환승하시면 됩니다. 30분 정도면 입구에 도착해요. | 지하철이나 버스로 갈 수 있어요. |
| 4 | (추가) 등산 코스가 어렵지는 않을까요? | 코스 난이도는 다양해요. 처음이시면 정릉탐방안내소 코스가 비교적 완만해서 추천드려요. | 초보자용 코스도 있어서 부담 없어요. |
| 종료 | "대화 종료" 버튼 클릭 | 한국어 / 베트남어 / 영어 요약 + 학습 피드백 표시 | 동일 (폴백 메시지) |

**음성 입력 사용 시**: STT 인식 결과가 textarea에 채워진 뒤 3초 카운트다운 → 자동 전송. 멘트 중간에 수정해야 하면 "취소" 버튼 누르고 키보드로 보정.

**NPC 음성 자동 재생**: 응답이 도착하면 브라우저 TTS(`ko-KR`)가 자동 재생. 시연 PC 스피커 출력 확인 필수. 토글로 OFF 가능.

**시연 멘트 예시**: "기존 6개 모드는 제시된 문항에 맞춰 학습합니다. 생성형 대화는 학습자가 원하는 주제로 자유롭게 대화하면서, AI가 매 발화마다 한국어 문법·표현을 교정하고, 마지막에 한국어·베트남어·영어 요약과 함께 학습 피드백을 돌려줍니다. 이번 시연에서는 음성 입력 후 3초 카운트다운으로 자동 전송되며, NPC 응답도 음성으로 들립니다."

## 폴백 시 발화

**LLM 응답 실패 (자동 mock 사용 시)**: "지금 네트워크가 잠시 불안정해서 기본 응답으로 데모를 이어 가겠습니다. 실제 환경에서는 LLM 응답이 매번 자연스럽게 달라집니다."

**Azure 발음 평가 실패 (demo provider 사용 시)**: "정밀 발음평가 v2는 안정화 단계라 오늘은 참고 평가 화면을 보여드립니다."

**시연 PC 마이크 인식 실패**: "마이크 환경 점검을 위해 텍스트 입력으로 전환하겠습니다." (생성형 대화는 텍스트 입력도 정상 작동)
