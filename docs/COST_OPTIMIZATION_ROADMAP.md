# KDLI 운영 비용 최적화 로드맵

## 목적

이 문서는 KDLI(한국어 학습 AI) 시스템을 운영하면서 **비용 투자로 정확도·기능을 향상시킬 수 있는 영역**을 정리한 의사결정 자료입니다. 각 항목은 현재 무료/저비용 구조의 제약과, 비용을 투입했을 때의 정량·정성 효과를 비교해 의사결정자가 그대로 검토할 수 있도록 작성합니다.

## 원칙

- **정직한 추정**: 낙관적 가정 없이 평균 사용량 기준으로 산정합니다.
- **구체 숫자**: 학습자 100명, 1인당 일일 평균 사용량 기준의 월 비용을 명시합니다.
- **대안 비교**: 옵션 A/B 형식으로 트레이드오프를 명시합니다.
- **의사결정자 언어**: 기술 용어는 최소화하고, "정확도 X% 향상", "월 $XX" 형태로 표시합니다.

## 표준 형식

각 항목은 아래 구조를 따릅니다:

```
### N. <영역>

**현재 상태**: <어떻게 작동 중>
**관련 명세**: <명세 번호>
**제약**:
- 정확도: <%>
- 속도: <ms>
- 기능 한계: <설명>

**투자 옵션**:

옵션 A — <이름>
- 대안: <기술·서비스>
- 월 비용 (100명 기준): $XX~XX
- 효과:
  - 정량: <%로 향상>
  - 정성: <설명>
- 도입 난이도: 하/중/상
- 도입 시점 추천: 시연 후 즉시 / 운영 1개월 후 / 정식 출시

옵션 B — ...

**의사결정 가이드**:
- 학습자 N명 도달 시 옵션 A 도입 권장
- 만족도 < X 시 옵션 B 검토
- 예산 $X 확보 시 즉시 적용
```

## 1. 카라오케 실시간 STT

**현재 상태**: 브라우저 Web Speech API로 단어 단위 매칭, 무료. Chrome/Edge에서만 동작.
**관련 명세**: 17, 22
**제약**:
- 정확도: 한국어 90~95% (학습자 발음·환경음에 민감)
- 속도: 인터림 응답 100~300ms
- 기능 한계: Safari/Firefox 미지원, 끊김·재인식 시 매칭 점프 발생, 인식 오류 누적 시 학습자가 실제와 다른 위치에 표시

**투자 옵션**:

**옵션 A — Whisper 청크 폴링**
- 대안: OpenAI Whisper API에 1~2초 단위 오디오 청크를 폴링 전송
- 월 비용 (100명 기준, 1인당 일일 평균 카라오케 5분): $90~180/월
- 효과:
  - 정량: 한국어 정확도 95~98%로 향상
  - 정성: 모든 브라우저에서 동작, 환경음에 강건
- 도입 난이도: 중 (청크 분할·역다중화 로직 필요)
- 도입 시점 추천: 학습자 30명+ 또는 카라오케 정확도 불만 누적 시

**옵션 B — Azure Continuous Recognition (실시간 스트림)**
- 대안: Azure Speech SDK의 continuous recognition으로 단어 단위 streaming
- 월 비용 (100명 기준): 약 $1,500/월 (시간당 $1, 100명 × 일 5분 × 30일)
- 효과:
  - 정량: 정확도 95%+ 동등, 지연 50~150ms (Whisper 대비 ↑)
  - 정성: 발음 평가 호출과 단일 SDK 통합, 단어 offset/duration 일치
- 도입 난이도: 상 (현재 Free F0 → Standard 전환, SDK wrapper 작성)
- 도입 시점 추천: 정식 출시 + 발음 평가도 함께 Standard 전환할 때

**의사결정 가이드**:
- 시연/PoC 단계에서는 현재 Web Speech 유지
- 학습자 30명+ 또는 Safari 사용자 비중 ↑ 시 옵션 A
- 발음 평가 Standard 전환 시점에 옵션 B 동시 도입 검토

## 2. q4 다국어 피드백 (정적 → 동적)

**현재 상태**: q4 종료 후 점수·미션 달성률 기반 3 tier 정적 템플릿 (한·베·영). LLM은 한국어 단일 출력만 수행.
**관련 명세**: 20-F-2
**제약**:
- 정확도: 학습자 발화 내용을 반영하지 못해 일반론적 피드백
- 기능 한계: 같은 점수대 학습자 모두 동일 문구

**투자 옵션**:

**옵션 A — LLM 출력에 vi/en 필드 추가**
- 대안: q4 종료 평가 LLM 호출의 응답 JSON에 `feedback_vi`, `feedback_en` 추가, 한 번의 호출로 3개 언어 동시 생성
- 월 비용 (100명 기준, 1인당 일일 q4 1회): $30~50/월 (gpt-4o-mini 기준 출력 토큰 약 3배 증가)
- 효과:
  - 정량: 학습자별 발화 기반 개인화 100% (현재 0%)
  - 정성: 베트남어 화자에게 한국어 표현 차이 설명, 영어 화자에게 발음 포인트 안내
- 도입 난이도: 하 (인프라 이미 있음, 프롬프트·파서만 확장)
- 도입 시점 추천: 시연 후 즉시 (가장 ROI 높음)

**의사결정 가이드**:
- 시연 후 첫 운영 사이클에 즉시 도입 권장. 비용 부담 작고 만족도 향상 폭이 큼.

## 3. LLM 모델 (gpt-4o-mini → gpt-4o)

**현재 상태**: 모든 q1~q4 평가·NPC 응답·교정·요약을 gpt-4o-mini로 수행 ($0.15/1M input, $0.60/1M output).
**관련 명세**: 7, 11, 12, 13
**제약**:
- 정확도: 한국어 자연스러움 약 70~80%, 평가 신뢰도 약 75% (sample 기반 추정)
- 기능 한계: 복잡한 맥락 추론 시 헛소리 발생, 격식체/일반체 구분 약함

**투자 옵션**:

**옵션 A — gpt-4o로 전체 전환**
- 대안: 동일 호출 흐름, 모델만 gpt-4o ($2.50/1M input, $10/1M output)
- 월 비용 (100명 기준, 1인당 일일 5턴 가정): 현재 $30~50 → $480~800/월
- 효과:
  - 정량: 한국어 자연스러움 90%+, 평가 신뢰도 88%+
  - 정성: 격식체/일반체 정확 구분, 복잡한 맥락 일관성, 학습자 수준에 맞춘 어휘 선택
- 도입 난이도: 하 (모델 ID 변경만)
- 도입 시점 추천: 학습자 만족도 조사 후 (mini로 충분히 좋다면 유지)

**옵션 B — 평가는 gpt-4o, 대화는 gpt-4o-mini (하이브리드)**
- 대안: 채점 정확도가 중요한 호출(q1~q4 평가, 발표 교정)은 gpt-4o, NPC 대화·후속 질문은 gpt-4o-mini
- 월 비용 (100명 기준): $150~250/월
- 효과:
  - 정량: 평가 신뢰도 85%+, 대화 자연스러움은 mini 수준 유지
  - 정성: 비용 효율적, 신뢰도가 중요한 영역만 향상
- 도입 난이도: 중 (호출 사이트별 모델 선택 로직)
- 도입 시점 추천: 운영 1개월 후 (어느 호출이 가장 부정확한지 데이터 누적 후)

**의사결정 가이드**:
- 학습자 만족도 조사에서 "AI 응답이 어색하다" 의견 다수 시 옵션 A 또는 B
- 예산 $500/월 미만이면 옵션 B 우선
- 평가 정확도 검증(항목 6) 결과 신뢰도 < 80% 시 평가 호출만이라도 옵션 A 부분 적용

## 4. Azure Speech 발음 평가 (Free F0 → Standard S0)

**현재 상태**: Azure Speech Free F0 사용 (월 5시간 제한, rate limit 5 req/sec).
**관련 명세**: 15
**제약**:
- 기능 한계: 100명 동시 사용 불가, 월 5h 초과 시 호출 실패
- SLA: Free 티어 SLA 없음

**투자 옵션**:

**옵션 A — Standard S0 전환**
- 대안: Pay-as-you-go ($1/시간, 시간 단위 청구)
- 월 비용 (100명 기준, 1인당 일일 발음 평가 5분): 약 $25/월
- 효과:
  - 정량: 사용량 무제한, rate limit 20 req/sec
  - 정성: SLA 99.9% 보장, 성능 안정
- 도입 난이도: 하 (Azure 포털에서 티어만 변경)
- 도입 시점 추천: 학습자 30명+ 또는 시연 직후

**의사결정 가이드**:
- 시연/PoC는 Free 유지 가능
- 학습자 30명+ 진입 즉시 Standard 전환 권장 ($25/월은 거의 무시 가능한 수준)

## 5. TTS (브라우저 → Azure Neural TTS)

**현재 상태**: 브라우저 SpeechSynthesis API, 무료, 음질 낮음 (특히 한국어).
**관련 명세**: 17, 20
**제약**:
- 정확도: 음질 60~70% (시스템 음성에 의존, 학습자 OS·브라우저별 편차 큼)
- 기능 한계: 페르소나 다양성 없음, 감정 표현 없음

**투자 옵션**:

**옵션 A — Azure Neural TTS**
- 대안: ko-KR-SunHiNeural / InJoonNeural 등 ($16/1M chars, neural 기준)
- 월 비용 (100명 기준, 1인당 일일 평균 200자 TTS): 약 $20~40/월
- 효과:
  - 정량: 음질 90%+ (사람과 거의 구별 불가)
  - 정성: 다양한 페르소나(성별·연령·톤), 감정 SSML 지원
- 도입 난이도: 중 (TTS 호출 추상화 + 캐싱 전략)
- 도입 시점 추천: 학습자 만족도 조사 후 또는 NPC 캐릭터 다변화 시점

**의사결정 가이드**:
- 시연/PoC는 브라우저 TTS 유지
- "AI 목소리가 부자연스럽다" 의견 다수 또는 NPC 페르소나 확장 시점에 도입

## 6. 평가 정확도 검증 (없음 → 사람 비교)

**현재 상태**: AI 평가의 신뢰도를 측정한 적 없음. q1~q4 점수가 실제 학습자 능력과 얼마나 일치하는지 미검증.
**관련 명세**: 34 (계획)
**제약**:
- 정확도: 검증 데이터 없음
- 기능 한계: AI calibration 불가, 의사결정자에게 신뢰도 제시 불가

**투자 옵션**:

**옵션 A — 일회성 사람 평가 비교 연구**
- 대안: 한국어 교사 N명(권장 5명)이 학습자 발화 50~100건을 독립 평가, AI 점수와 비교 → calibration 보고서 작성
- 월 비용: 일회성 $1,000~3,000 (교사 시간당 $30~50, 분석 포함)
- 효과:
  - 정량: 평가 신뢰도 측정값 확보 (AI vs 사람 상관계수, 표준편차)
  - 정성: 의사결정자에게 객관적 신뢰도 보고, 모델 업그레이드(항목 3) ROI 근거
- 도입 난이도: 중 (데이터 수집·평가 인력 섭외)
- 도입 시점 추천: 운영 1개월+ 후 (학습자 발화 데이터 충분히 누적된 시점)

**의사결정 가이드**:
- 운영 1개월 시점에 일회성 실시 권장
- 결과에 따라 항목 3(LLM 모델 업그레이드)의 도입 여부 결정

## 7. 인프라 (Free → Pro)

**현재 상태**: Supabase Free, Vercel Hobby.
**관련 명세**: (운영 인프라)
**제약**:
- Supabase Free: 500MB DB, 1GB 파일 스토리지, daily backup 없음
- Vercel Hobby: 100GB 대역폭, 상용 사용 약관 위반 위험
- SLA: 둘 다 없음

**투자 옵션**:

**옵션 A — Supabase Pro + Vercel Pro**
- 대안: Supabase Pro $25/월 + Vercel Pro $20/월
- 월 비용: $45/월
- 효과:
  - 정량: 8GB DB, 100GB 파일, daily backup 7일, 1TB 대역폭
  - 정성: SLA 99.9%, 분석 도구, 상용 사용 가능
- 도입 난이도: 하 (대시보드에서 업그레이드)
- 도입 시점 추천: 학습자 50명+ 또는 운영 시작 직전

**의사결정 가이드**:
- 시연/PoC는 Free 유지 가능
- 정식 운영 시작 시점에 즉시 Pro 전환 (월 $45는 거의 무시 가능, 약관/SLA 리스크 회피)

## 향후 자동 추가 규칙

향후 명세 작업 중 비용·정확도 트레이드오프가 발견되면 본 문서에 항목을 자동 추가합니다. 형식은 위 "표준 형식"을 따릅니다. 추가 시 다음 메타데이터를 포함합니다:

- 발견된 명세 번호
- 발견 일자
- 현재 무료/저비용 선택의 근거

이로써 의사결정자는 "어떤 영역에 얼마를 투자하면 어떤 향상을 얻는지"를 한 문서로 파악할 수 있습니다.
