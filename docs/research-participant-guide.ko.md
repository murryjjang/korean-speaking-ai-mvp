# 한국어 말하기 학습 시험운영 안내 (참여자용)

## 1. 시험운영 참여 안내

본 시험운영은 한국어 말하기 학습 시스템(KDLI Korean MVP)의 효용성을 확인하기 위한
목적으로 진행됩니다. 학술 연구 및 KDLI 보고에 활용됩니다.

## 2. 접속 방법

1. 운영자에게서 받은 사이트 URL을 웹 브라우저에서 엽니다.
2. **참여자 코드**(예: P001)를 입력합니다.
3. **PIN**이 발급된 경우 함께 입력합니다.
4. 첫 접속 시 동의 화면이 표시됩니다. 본문을 자세히 읽고 동의 여부를 선택하세요.

## 3. 학습 모드

동의 후 4가지 학습 모드를 자유롭게 사용할 수 있습니다:

| 모드 | 설명 |
|---|---|
| 생성형 자유 대화 | 페르소나 4명(친구 여/남, 도우미 여/남) 중 선택해 일상 대화 연습 |
| 말하기 평가 (q1~q4) | 따라 읽기·묘사·그림 설명·대화 미션 |
| 발표 연습 | 주제 발표 + 자동 평가 |
| 읽기 연습 | 지문 낭독 + 발음 평가 |

학습 진척은 `/research/student/progress`에서 확인할 수 있습니다.

## 4. 수집되는 데이터

- 학습 활동 기록 (모드·세션 시작·종료 시간)
- 음성·음성 인식 텍스트·NPC 응답
- 평가 점수·피드백
- 동의 시점의 IP 주소(앞 24비트만 익명화) 및 사용자 에이전트

## 5. 데이터 활용

- 학술 연구 (논문·학회 발표)
- KDLI 보고
- 시스템 개선

논문·보고서에 인용되는 데이터는 모두 참여자 식별이 불가능한 형태로 가공됩니다.
참여자 코드(예: P001)로만 표기되며, 이름·국적·연락처는 절대 공개되지 않습니다.

## 6. 보관 기간

연구 종료 후 2년 보관. 보관 기간 종료 시 모든 식별 가능 정보는 삭제됩니다.

## 7. 참여자 권리

- 언제든 참여를 철회할 수 있습니다 — 운영자에게 연락
- 본인 데이터 열람: 진척 페이지에서 "내 데이터 CSV 다운로드"
- 본인 데이터 삭제 요청 가능

## 8. 문의

질문·기술 문제·철회 요청은 운영자에게 직접 연락해 주세요.

## 9. 자주 묻는 질문

**Q. 로그인 후 곧바로 로그인 화면으로 돌아갑니다.**
브라우저 쿠키 설정이 차단되어 있을 수 있습니다. 시크릿 창이나 다른 브라우저에서
시도해 보세요.

**Q. 마이크가 인식되지 않습니다.**
브라우저 권한에서 사이트의 마이크 사용을 허용했는지 확인하세요. Chrome·Edge·Safari
권장.

**Q. 음성이 들리지 않습니다.**
시스템 음량과 브라우저 탭의 음소거 상태를 확인하세요.

**Q. 학습 도중 종료해도 데이터가 남나요?**
네, 그 시점까지의 데이터는 저장됩니다. 추후 이어서 학습할 수 있습니다.
